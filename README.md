第一步 选择数据集和决策者

数据集来源与规模：本dashboard使用的数据集为 Kaggle 平台上的 College Major ROI 数据集，来源链接为 https://www.kaggle.com/datasets/sergionefedov/college-major-roi ，包含约三万条基于乔治城大学 CEW、FREOPP 及 College Scorecard 校准的合成毕业生记录，文件体积远低于 25MB。

决策者定位：我们将dashboard的决策者明确为高中升学顾问和高中毕业生。该角色需要评估不同专业和院校组合的长期经济价值，帮助学生在预算约束下做出明智的升学选择。

第二步 为仪表盘提供合理性

谁会看一次，多久看一次：高中升学顾问会在每年大学申请季或每学期集中查看该仪表盘，用于系统性地指导学生的选校与选专业策略。

它支持什么决定：如果升学顾问在仪表盘上看到某个专业的净投资回报率为负或极低，他们就会建议学生重新考虑该专业，或者转向性价比更高的中低等级院校与实用型专业。

他们今天没有它该怎么办：如果没有这个仪表盘，顾问只能依赖传统的名校光环或主观经验，这可能导致学生背负巨额债务却面临低薪，在毕业后十年内造成数十万美元的机会成本损失。

为什么选择dashboard而不是每周邮件：因为每位学生的预算、成绩、地域偏好和职业目标都各不相同，静态的每周报告或邮件无法提供多维度的个性化筛选与实时对比功能。

第三步 决定什么重要

最多三个头条数字：dashboard顶部使用 st.metric 展示三个头条数字。第一个是中位数净投资回报率，用以抵抗极端值干扰并反映典型回报水平。第二个是正向投资回报占比，通过计算正向回报的均值反映不亏本的概率。第三个是中位数十年总收入，用于衡量绝对收入水平。

一两张支持性图表：第一张是专业大类平均投资回报柱状图，用于对比不同领域的长期回报。第二张是成本与投资回报散点图，用于揭示高学费是否一定等于高回报。

只有当事人真正需要的筛选条件：侧边栏只放置三个真正需要的筛选条件，即专业大类、院校等级和地理位置。

选择不展示的两件事以及原因：不展示毕业生唯一标识，因为它对分析毫无意义。不展示个人的 GPA、实习经历和是否按时毕业，因为这些属于个人特质，决策者在选专业时无法立刻改变，放入主页面会干扰对专业本身价值的判断。

数据中可能误导观众的内容：绝对金额与百分比回报的差异是最容易误导人的。常春藤名校艺术专业的绝对回报可能勉强为正，但百分比极低，而州立大学计算机科学的百分比极高，仪表盘必须同时标注这两个指标。同时，由于数据为合成数据，必须在页面底部注明其局限。

决定顺序：页面从上到下应遵循重要性顺序。顶部放置头条数字，回答现在有什么问题。中间放置解释数字变化原因的图表。底部放置底层数据表格，供想要深入挖掘的人使用。

第四步 确定刷新频率

数据应多久更新一次：数据应每年更新一次，即在每年大学录取数据和新毕业生收入数据发布后进行更新。

应该多久复习一次，这是否也是同一回事：顾问应在每年申请季前复习一次，这与数据更新频率保持一致，并非同一回事，但节奏相符。

哪些内容应该随时间追踪，哪些内容应该触发行动：应该随时间追踪中位数净投资回报率的变化趋势。当某一特定专业的正向投资回报占比跌破百分之五十时，应当触发顾问的警觉，并建议顾问拿起电话与学生重新评估选校名单。

陈旧数据的成本是多少：如果仪表盘落后一天，不会产生实质影响。但如果落后一年，顾问可能会基于过时的薪资和成本数据给出错误建议，导致学生做出错误的升学决策，付出高昂的时间与金钱代价。由于目前使用的是静态 Kaggle 快照，我们会在仪表盘页面底部添加一行说明文字，明确标注数据期间为 Kaggle 快照，并注明在生产环境中应使用的刷新频率为每年一次。
